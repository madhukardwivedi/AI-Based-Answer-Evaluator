# Included demo materials

Start with the [setup README](../README.md) and [feature walkthrough](../docs/DEMO_GUIDE.md). These synthetic sample documents are provided for demonstration. They do not include application credentials, the local database, or stored user uploads. Names/roll numbers are demo identities, not institution records.

## Main end-to-end demo: Mathematics, Class 10, 50 marks

| File | Use |
|---|---|
| [Maths question paper](../class10_math_exam_50_marks.pdf) | 2-page digital PDF; 12 questions including Q10(a)/Q10(b), 50 marks. |
| [Teacher answer key and suggested rubric](../docs/MATHS_REFERENCE.md) | Copy references into Questions before evaluation. |
| [Rahul 101](../class10_math_sample_answer_sheet_rahul_101.pdf) | 3-page image-only answer sheet; start here. |
| [Priya 102](../class10_math_answer_sheet_priya_verma_102.pdf) | 3-page image-only answer sheet. |
| [Aman 103](../class10_math_answer_sheet_aman_gupta_103.pdf) | 3-page image-only answer sheet with deliberately incorrect work. |
| [Sneha 104](../class10_math_answer_sheet_sneha_reddy_104.pdf) | 3-page image-only answer sheet with deliberately incorrect/partial work. |
| [Five-student roster](../samples/student-roster-sample.csv) | Import in Students; four sheet owners plus Arjun 105 without a supplied sheet. |
| [Twenty-student roster](../test_students.csv) | Optional larger import/selection demonstration. Use instead of the smaller roster, or expect duplicate rows to be skipped. |

Known mismatch: the question paper prints Q3, but answer sheets print Q3(a) for the distance problem. See the walkthrough's explicit review/mapping instructions. Even the Rahul sheet is not a guaranteed perfect solution. These files test transcription of mistakes, not just answer correctness.

| File | Exam / purpose |

There is no matching student answer sheet for the seven-question Science exam. Do not assign a Maths sheet to it.

Root PDF locations are intentional: existing local diagnostic scripts use these paths. GitHub's individual PDF viewer previews files; after cloning, choose the local files in the app's upload picker. PDFs are not automatically imported into the database.

## Excluded local artifacts

The saved `exam-…-results.csv` from a previous local run is not published: results should be generated by the recipient's own demo, not presented as reproducible expected grades. The local project proposal PDF, stored uploads, secrets and database are also excluded. CSV/XLSX results are created through the Results screen after review.
